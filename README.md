# NataArsip - SaaS Document Management System

A highly secure, multi-tenant Software-as-a-Service (SaaS) Document Management System built with **Laravel 13**. Designed specifically for institutions and enterprises to streamline file archiving, secure data retrieval, and operational workflows within isolated organizational workspaces.

## Core Architecture & Security (Implemented)

* **Multi-Tenancy (SaaS-Ready):** Architectural foundation specifically designed for multi-tenant environments, ensuring strict data isolation and system scalability across different institutions.
* **Advanced Role-Based Access Control (RBAC):** Comprehensive user hierarchy system implemented with strict permission boundaries (**Super Admin, Tenant Admin, Manager, Staff**).
* **Enterprise-Grade Security:** Integrated **Two-Factor Authentication (2FA)** to provide an additional layer of protection for sensitive institutional data and user accounts.
* **Clean Architecture:** Built with a strict separation of concerns, utilizing Service Classes to handle complex business logic and future feature expansions.

## Tech Stack
* **Core:** Laravel 13, PHP
* **Frontend:** Tailwind CSS
* **Architecture:** SaaS Multi-Tenancy, Modular MVC, Service Layer Pattern
* **Security:** 2FA, RBAC
